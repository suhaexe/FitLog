# FitLog — Workout Library

A dark, no-nonsense gym companion. Browse 12 workouts, add them to today's plan (max 5), save for later, and track your daily minutes and calories.


## Technologies Used

- Next.js (App Router)
- React
- Tailwind CSS 
- lucide-react (icons)
- react-hot-toast (notifications)

## Features

1. Browse all workouts in a responsive grid with sort by Duration, Calories, or Rating
2. Workout detail page with instructions, specs, and Add to Plan / Save for Later buttons
3. Today's Plan with a cap of 5 exercises and live totals for Exercises, Minutes, and Calories
4. Saved list and Mark as Done functionality with toast notifications
5. Plan and saved data persists in localStorage, so it survives page reloads
6. 404 page for unknown routes
